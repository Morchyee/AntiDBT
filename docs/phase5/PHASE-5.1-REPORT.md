# antiDBT Phase 5.1 交付报告：连贯性、低延迟与排版滚动专项优化

## 一、完成目标概览

本轮优化围绕 Phase 5.1 核心体验与补充指令进行，已完成代码修改、全量测试验证与便携包发布：

1. **彻底移除“等待译文...”占位符与“待更新”标签**：
   - 主界面与渲染管线彻底移除 `等待译文…` 占位字符串。
   - 彻底移除 `  · 待更新` 视觉标签。
   - 原文在识别到后立即就地渲染呈现；译文尚未返回时保持空白，绝不显示虚假占位符；中间草稿有效时平滑保留避免闪烁；最终译文到达后即时更新。
2. **收起（紧凑）模式全面支持流畅滚动浏览历史**：
   - 无论处于收起模式还是展开模式，鼠标悬停于字幕区域时均可通过鼠标滚轮或触控板双指滚动浏览历史字幕。
   - 紧凑模式下字幕视口自适应内容高度（上限为 1~2 行字幕高度），用户在滚动翻阅历史时**不会改变窗口紧凑尺寸**，亦**不会触发窗口拖拽**。
3. **大幅降低滚动灵敏度与触控板平滑度支持**：
   - 采用像素级滚动单元（`VirtualizingPanel.ScrollUnit = Pixel`），重写了 `PreviewMouseWheel` 处理逻辑。
   - 标准鼠标滚轮每档（Delta 120）位移严格控制在 1～1.5 行文本高（~30-34px），消除 WPF 默认的跳跃式多行翻页感。
   - 触控板微小 Delta（如 10~30）等比平滑微调，实现丝滑连续滚动。
   - 向上滚动浏览历史时**自动暂停最新字幕跟随**；回到底部时（或点击“↓ 回到底部”）**自动恢复跟随**。
4. **自然连续排版（第二句不强制另起一行）**：
   - 重构了 `SubtitleProjection.cs` 的段落与分句逻辑。
   - 连续讲话中的相邻句子在同一段落内连续流动排版（如 `Hello, how are you? I'm fine, thank you.` 在同一行排版，达到边缘时自然 TextWrapping）。
   - 英文单词与句子间自然保留 1 个空格；中文字符与中文标点符号（`。`、`？`、`！`、`，` 等）间绝无多余空格。
   - 仅在会话重置、明确的长时间停顿（静音或音频时间差 >= 2.5s，时钟差 >= 3.5s）或段落长度达到上限（>= 180 字符）时才启动新段落。
5. **完整保留全部 Provider 架构与便携包生成**：
   - 10 个 ASR Provider 与 14 个 MT Provider 完好保留。
   - 构建生成了独立的 `publish/antiDBT-phase5.1-win-x64` 发布包与 `antiDBT-phase5.1-win-x64.zip`。
