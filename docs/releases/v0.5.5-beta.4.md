# antiDBT v0.5.5-beta.4 · 本地英文 ASR 完整版

Windows x64 自包含便携包包含 Sherpa-ONNX Streaming Zipformer English 20M int8 模型及运行库，无需安装 SDK、Python、Go 或提供 Groq Key。完整解压后进入 antiDBT 文件夹，双击 antiDBT.exe。

[完整中文部署教程](../LOCAL_ASR_SETUP.zh-CN.md)

本地 ASR 仅支持英文。首次设置中选择“本地流式识别 (sherpa-onnx)”，模型路径使用 models/sherpa-onnx，源语言 English。仅需原文时目标语言也选 English；需要中文字幕时选择简体中文并配置独立 MT 服务。此包不提供完全离线英译中。

当前本地 Phase 5.5.4 源码包含连续分句、上下文翻译及统一字幕滚动容器。发布验证结果、精确提交、CPU 实测、资产大小和 SHA256 由发布时的报告记录，不引用历史测试结论。

已知限制：英文专用模型；识别准确率取决于音频；云端 MT 需要网络、凭据及额度；硬件、多个显示器和所有 DPI 组合未逐一覆盖。模型采用 Apache-2.0，antiDBT 主程序采用 MIT；完整授权材料随包提供。
