# antiDBT 第四阶段：极简字幕悬浮窗 UI 优化完成报告

分支：`phase4-multilingual-ui`。已完成极简悬浮窗 UI 优化，全套测试通过，生成独立交付包并验证实机运行。

## 一、主界面精简优化成果

1. **移除常驻技术信息与干扰组件**：
   - 从主窗口完全移除了 `ASR · ...` / `MT · ...` 服务标签；
   - 移除了底部 `p95 ASR≈... · MT ...` 延迟统计（内部 LatencyMonitor 保留供高级诊断与设置面板查看）；
   - 移除了底部独立的状态栏与音频电平进度条，彻底去除了底部容器行。
   - 窗口纵向高度缩减超过 50%，双语字幕成为窗口绝对的视觉核心。

2. **实时聆听状态移至右上角**：
   - 在顶部工具栏右侧展示紧凑状态胶囊：
     - `● 聆听中`（绿色圆点 + 绿色文本，运行状态）
     - `● 未开始`（灰色圆点 + 灰色文本，停止/就绪状态）
     - `● 连接中`（黄色圆点 + 黄色文本，连接/切换状态）
     - `● 连接异常`（红色圆点 + 红色文本，异常状态）
   - 鼠标悬停（ToolTip）可查看详细信息（含已丢弃音频块、失败原因或直通说明）。
   - 状态与 CaptionPipeline 生命周期严格同步。

3. **语言选择整合至顶部工具栏**：
   - 移除原先在字幕上方永久占位的两组大型下拉框。
   - 顶部工具栏展示紧凑按钮：`源语言 → 目标语言 ▾`（如 `自动检测 → 中文（简体） ▾`）。
   - 点击弹出双语选择卡片，完整保留：源语言选择、目标语言选择、一键交换按钮（`⇄`）、搜索、最近使用标记（`★`）及 Provider 能力限制提示。
   - 关闭弹窗后主窗口只保留语言方向指示，极大减少视觉占用。

4. **主窗口终态布局**：
   - 顶部工具栏：
     `antiDBT  |  源语言 → 目标语言 ▾  |  开始  展开  原文  字号  ⚙  |  ● 聆听中  ×`
   - 主体视口：仅保留英文原文与中文译文（或展开模式下的历史滚动列表）。
   - 全窗口支持自由拖拽移动（点击标题栏或背景空白区域均可拖动）。
