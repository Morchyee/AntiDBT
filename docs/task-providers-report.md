# Task 3 provider implementation report

Implemented only `src/AntiDbt.Providers`, `tests/AntiDbt.Providers.Tests` and this report; the test executable writes the requested `artifacts/provider-tests.json` evidence. Core remains provider-neutral.

Public signatures:

```csharp
AppSettings ProviderCatalog.DefaultSettings();
IAsrProvider ProviderCatalog.CreateAsr(AsrConfiguration config);
ITranslationProvider ProviderCatalog.CreateTranslator(TranslationConfiguration config);
IAsrSession VolcengineAsrProvider.CreateSession(AsrConfiguration configuration);
VolcengineMachineTranslationProvider(TranslationConfiguration config, HttpClient? client = null);
Task<string> VolcengineMachineTranslationProvider.TranslateAsync(TranslationRequest request, CancellationToken cancellationToken);
```

Defaults select `VolcengineAsr2` / optimized `bigmodel_async`, resource `volc.seedasr.sauc.duration`, `bigmodel`, automatic source language (empty), and `VolcengineMachineTranslation` / public `matx_translate`, resource `volc.speech.mt`; target zh, medium font, source visible and topmost. No credentials are supplied. New auth uses `ApiKey`; legacy uses `Options["appId"]` and `Secrets["accessKey"]`; resource override uses `Options["resourceId"]`.

ASR sends full JSON configuration (PCM/raw 16000 Hz, 16-bit mono, utterances, optimized nonstream second pass, punctuation/ITN), positive sequence packets and negative-sequence empty final packet. Receives fragmented binary messages, validates flags/length/serialization, caps wire and decompressed payload at 4 MiB, and parses result objects and optional payload_msg wrappers. Local session/ordinal IDs remain stable across shifted timestamps and timing-only revisions. Cumulative snapshots skip the finalized prefix through a scalar end-time watermark, releasing finalized text immediately. The provisional suffix is capped at 512 rows. Splits/merges preserve its unchanged prefix and emit tombstones for superseded suffix rows before replacement. Unsupported overlap across the finalized boundary or a final after a provisional utterance is rejected rather than silently duplicating finalized text. Complete sends final packet under a three-second bound; pending result drain ends after three seconds. One result reader is allowed per session.

MT sends only documented source/target/text-list fields, omitting empty or application `auto` source; scheduler context is deliberately not a request field. HTTP redirects are disabled. Injected HttpClient is restricted to localhost testing because its redirect policy cannot be inspected. Public endpoints require HTTPS/WSS and openspeech.bytedance.com; HTTP/WS is allowed only for loopback. Errors never include server bodies, headers or credential values. LiveInterpret remains rejected pending verified mainland proto/event semantics.

Validation: 26/26 actual localhost HTTP/WebSocket tests passed. Tests cover default selection/gate; new and legacy MT authentication; exact MT body and source omission; HTTP/API errors and redirects; cancellation; literal ASR config/audio/final header/frame bytes; fragmented gzip responses; duplicate suppression, revisions and final transition; truncated/unknown-flags/bad-gzip/unexpected-result-shape/business/protocol errors; a decompression bomb; ASR cancellation; bounded final drain; endpoint and missing credential rejection; shifted-start/timing-only revisions; split/merge tombstones applied through real SubtitleStore; unchanged provisional-prefix retention; repeated finalized-prefix deduplication; extended header nibbles; actual default ASR→Store→MT automatic language omission; official MT en-US→en and zh-CN→zh aliases; repeated disposal and concurrent completion. Test project and provider project build with zero warnings/errors using local NuGet.Config, `UseSharedCompilation=false`, `-m:1`, and workload resolver disabled.

Sandbox loopback connects returned Windows socket error 10013. A narrowly approved elevated run of the built test executable used its own ephemeral localhost servers and dummy credentials only. Evidence is `artifacts/provider-tests.json`. `tests/AntiDbt.Providers.Tests/behavioral-red.json` records the real failing final-drain regression before its fix; `red.log` records an earlier failed build with no useful diagnostic and is not claimed as behavioral TDD evidence. `review-red.json` records six review cases failing before fixes, `language-red.json` records the language-alias failure before normalization, and `suffix-red.json` records unchanged provisional-prefix failure before preserving that prefix. The original other feature tests were added after initial adapter implementation, so full initial test-first coverage is not claimed.

Official source contract is documented in [PROVIDER-SPECS.md](PROVIDER-SPECS.md): [ASR protocol](https://docs.volcengine.com/docs/6561/1354869?lang=zh), [optimized bidirectional evidence](https://docs.volcengine.com/docs/DoubaoVoice/speaker-separation?lang=zh), [authentication](https://docs.volcengine.com/docs/6561/2534847?lang=zh), [ASR result reference](https://docs.volcengine.com/docs/6561/2628951?lang=zh), [MT API](https://docs.volcengine.com/docs/DoubaoVoice/MachineTranslationLargeModel-APIAccessDocumentation?lang=zh).

Remaining limits: no real cloud handshake, credentials, entitlement, audio fixture, ASR quality/latency, live correction fixtures, or translation output validation. Local reconciliation assumes ordered, non-overlapping cumulative utterances and a final prefix. With unchanged suffix cardinality, identities follow ordinal position; changed cardinality retires only the affected suffix. Real cumulative response shapes and resegmentation across a finalized boundary remain cloud-fixture verification gates. Optional generic/OpenAI adapters were not added. Mainland LiveInterpret2 remains unavailable until current official mainland protobuf/events and dual incremental texts are independently verified.

Review source verification: the official MT reference was re-read through indexed official documentation on 2026-10-14. Its language support table lists `en`, `zh` (simplified), and `zh-Hant` (traditional); the provider maps common configured regional aliases to these documented codes. Public docs lookup used no credentials or authenticated cloud requests.
