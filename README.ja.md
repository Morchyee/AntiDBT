## 📖 プロジェクト概要

**antiDBT** は、Windows 10/11 向けに独自に設計・実装されたデスクトップリアルタイム二言語字幕フローティングオーバーレイクライアントです。Windows WASAPI ループバック経由で再生中の音声を直接キャプチャし、音声区間検出（VAD）、低遅延音声認識（ASR）、機械翻訳（MT）サービスを組み合わせて、滑らかで自然にレイアウトされた二言語字幕を画面上にリアルタイム表示します。

本プロジェクトはクリーンルーム開発手法を採用しており、**豆包（Doubao）公式の独自コード、非公開プロトコル、秘密鍵などは一切使用していません**。海外の動画視聴、生配信の同時通訳、国際オンライン会議、語学学習などのシーンに最適です。

## ✨ 主な機能

### 1. 🛡️ 産業グレード高信頼性アーキテクチャ (Phase 5.3 の進化)
- **停止時の末尾文ドロップ防止（有界ドレイン）**：「停止」をクリックした際、有界ドレイン期間（Bounded Drain）に入り、キューイング済みの音声ブロック、遅延した Final 認識結果、および対応する翻訳がすべて完了・描画されてから安全にシャットダウンされます。
- **ゴースト訳文の自動消去と下書き互換性検証**：ASR の原文修正でテキストが空になったり文脈が更新された場合、無効になった古い訳文を即座に破棄。プレフィックス拡張による下書き検証により、遅れて届いた古い結果が現在の字幕を上書きすることはありません。
- **韓国語・多言語スペース保持**：ストリーミング処理中に韓国語などの単語間スペースが失われる不具合を解消し、自然な分かち書きと高い可読性を維持します。
- **健全性しきい値に基づく再試行予算とレート制限バックオフ**：1回の音声送信成功だけで再試行予算をリセットせず、継続的な安定通信を確認した後にのみリセット。HTTP 429 エラー時の `Retry-After` ヘッダーを正確に遵守し、無駄なリクエストや余分な課金を防ぎます。
- **詳細な動作状態インジケーターと無音診断**：
  - 🟢 リスニング中 / 🟡 接続中 / 🔴 異常 / ⚪ 待機中。
  - 音声認識は正常だが機械翻訳のみ異常な場合はアンバー色（#FFB300）で警告し、「停止」ボタンは引き続き安全に使用可能。
  - 音声が無音状態（3.0秒以上）の場合、「接続済みですが音声信号がありません（無音）」と正確に診断し、ネットワーク障害と明確に区別します。

### 2. 🎨 本格的な透過率調整対応フローティングウィンドウ (Phase 5.2)
- **0%～100% 背景不透明度スライダー**：「設定 → 外観」から再起動不要でリアルタイムに透明度を調整可能。
- **文字と背景の完全分離**：字幕テキスト、ボタン、アイコンは常に 100% 不透明・高コントラストを維持し、全体がぼやけることはありません。
- **透過とクリック貫通防止**：背景は透けて奥の動画が見えますが、0% 透明度でもマウスの当たり判定は有効であり、誤って背後のウィンドウをクリックしてしまう事故を防ぎます。

### 3. 📐 自動フィットする弾性ビューポート
- **縦方向の自動全高拡張**：ウィンドウを下方向に広げると、字幕履歴エリアが利用可能な高さ全体を自動的に満たし、広い画面でより多くの文脈を把握できます。
- **横方向の自然な折り返し**：ウィンドウ幅に合わせて原文と訳文が自然に折り返され、文字が見切れたり途切れたりしません。
- **スマート「↓ 最下部へ」ボタン**：字幕ビューの右下オーバーレイに正確に配置され、ウィンドウサイズ変更時も適切な位置を維持します。

### 4. 📜 滑らかなピクセル単位スクロールとスマート追従ロック
- **ピクセル単位の慣性スクロール**：マウスホイールや高精度タッチパッドによる微小な移動でも滑らかにスクロール。
- **追従一時停止保護**：過去の字幕を読み返すために上へスクロールすると、自動スクロール追従が一時停止します。最下部に戻るか「↓ 最下部へ」をクリックすると追従が再開。新しい字幕が届いても、読書中に無理やり最下部へ戻されることはありません。

### 5. ⚙️ 非侵入型設定パネルとローカルセキュリティ
- **キャプチャを止めない設定画面**：設定パネルを開いたりキャンセルしても、音声キャプチャは中断されず、字幕履歴もクリアされません。外観の変更は即座に反映され、主要設定の変更時のみ1回だけ安全に再起動します。
- **ローカル LLM 対応**：明示的な許可設定により、ローカルで実行されている Ollama、LocalAI、LM Studio、または OpenAI 互換エンドポイント（`http://127.0.0.1` / `localhost`）に接続可能。外部クラウドに対しては厳格に HTTPS を要求します。

### 6. 📊 詳細な遅延計測テレメトリ
- 軽量でスレッドセーフな遅延コレクターを内蔵。`QueueWaitMs`（キュー待ち）、`AsrServiceMs`（音声認識時間）、`MtDebounceWaitMs`（デバウンス待ち）、`MtServiceMs`（翻訳時間）、`UiApplyMs`（描画時間）をミリ秒単位で計測。
- ワンクリックで匿名化された統計（中央値/p95）を JSON エクスポート可能。API キー、トークン、原文、訳文、音声データは一切含まれません。

### 7. 🔌 モジュール式 Provider エコシステム
- **音声認識（ASR）**：Groq Whisper（超低遅延）、Volcengine ASR 2.0、Azure Speech SDK、Google Cloud Speech V2 など。
- **機械翻訳（MT）**：DeepL API、OpenAI 互換 LLM（Ollama、DeepSeek、GPT-4o、Claude など）、Groq LLM、Volcengine MT、Azure Translator、Google 翻訳、Baidu 翻訳、Alibaba Cloud 翻訳など。

### 8. 🔒 ローカル認証情報の安全保護
- すべての API キーやパスワードは、**Windows DPAPI（Data Protection API）** を使用して現在の Windows ユーザー資格情報で暗号化され、ローカルの `data/settings.json` に安全に保存されます。

## 🚀 クイックスタート

### 1. ダウンロードと起動
1. [GitHub Releases](https://github.com/Morchyee/AntiDBT/releases) から最新の `antiDBT-v0.5.3-beta-win-x64.zip` をダウンロードします。
2. 任意のフォルダ（例：`D:\Tools\antiDBT\`）に解凍します。
3. 解凍先の `antiDBT.exe` をダブルクリックして起動します。

### 2. 音声認識と翻訳の設定
1. 右上の歯車アイコン **⚙** をクリックして設定を開きます。
2. **音声認識**：利用したい Provider（推奨：`GroqWhisper` または `VolcengineAsr2`）を選択し、API キーを入力します。
3. **翻訳サービス**：翻訳 Provider（推奨：`DeepL` または高速モデルを使った `OpenAiCompatible`）を選択し、API キーとモデルを入力します。
4. **外観設定**：「ダーク / ライト / システム準拠」テーマを選択し、**「背景不透明度」** スライダーで透明度を調整します（70%～85% 推奨）。
5. 「設定を保存」をクリックします。

### 3. 利用開始
- ツールバーの **「開始」** ボタンをクリックします。
- PC で動画、配信、音声会議などを再生すると、リアルタイムで二言語字幕が表示されます。
- API クォータを消費せずに動作を確認したい場合は、メインウィンドウで右クリックして **「ローカルデモ」** を選択してください。

## 🛠️ ソースコードからのビルドとテスト

C# 13 および .NET 9 WPF で開発されています。再現可能なビルドのため、`global.json` で SDK 9.0.319 に固定されています。

### 必須環境
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) (9.0.319 推奨)
- Windows 10/11 x64
- PowerShell 7 (`pwsh`)

### ビルド手順
```powershell
# リポジトリのクローン
git clone https://github.com/Morchyee/AntiDBT.git
cd AntiDBT

# ソリューションのビルド (Release)
dotnet build AntiDbt.sln -c Release

# 全 12 件の自動検証テストを実行
pwsh -File scripts/verify-all.ps1 -SkipRestore

# 自己完結型ポータブルパッケージの作成 (SHA256 生成含む)
pwsh -File scripts/build-candidate-package.ps1 -Version "0.5.3-beta"
```

## ⚠️ 既知の制限事項

1. **クラウド API の認証情報**：実際の音声認識および機械翻訳を利用するには、各サービス提供元（Groq、DeepL、火山引擎、OpenAI など）の API キーが必要です。
2. **WASAPI 排他モードの制限**：特定の DAW やプレーヤーが排他モード（Exclusive Mode）で音声を出力している場合、キャプチャできないことがあります。共有モード（Shared Mode）でご使用ください。
3. **ファイアウォール**：初回起動時に Windows Defender ファイアウォールの通信許可ダイアログが表示された場合は、API 通信のためにアクセスを許可してください。

## 🛡️ プライバシーとセキュリティ

- **トラッキングゼロ**：antiDBT は専用サーバーを持たず、利用状況の追跡やテレメトリ収集は一切行いません。
- **P2P ダイレクト通信**：音声データおよびテキストは、ユーザーが設定した各社 API エンドポイントとの間でのみ送受信されます。
- **DPAPI 暗号化**：機密情報は Windows アカウントに紐づけてローカルで暗号化されます。
